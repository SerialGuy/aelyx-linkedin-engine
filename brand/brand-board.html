Behind the buildaelyx.ai
Rules the engine will enforce
  • The model never draws. It only fills fields (headline, emphasis word, number, steps); Python renders the layout from locked tokens, so every post is on-brand.
  • Always: logo top-left, "AELYX // n" index top-right, corner ticks, mono footer with content type and aelyx.ai.
  • One italic serif emphasis word per headline, in Signal blue (or light blue on Ink). Nothing else is blue.
  • Canvas rotates Paper, Ink, Stone, Signal blue, with Paper and Ink the most frequent. No gradients, no stock imagery, no robot or brain art.
